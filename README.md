# 🏎️ KESTREL GT-1: Electric Performance Car Website

A modern, responsive single-page website for the **Kestrel GT-1**, a fictional
all-electric performance car. The site walks visitors through the car's design,
performance, customization and pricing, ending with a reservation form.

## ✨ Features
- Hero section with animated performance counters (0–60, top speed, range)
- Scroll-triggered animations
- Design section highlighting the active aero splitter, beltline and light bar
- Performance section with power and torque figures
- Interactive configurator: choose from 5 exterior finishes and 2 wheel styles
- Price updates automatically based on the selected options
- Standard vs Performance trim comparison table
- Reservation form with a deposit amount slider and a confirmation message
- Responsive layout with a mobile navigation menu

## 🛠️ Built With
HTML5, CSS3, JavaScript (vanilla)

## ⚠️ Note
The Kestrel brand and the GT-1 are fictional and were created for a portfolio
project. The reservation form is a front-end demo: no data is sent or stored.
